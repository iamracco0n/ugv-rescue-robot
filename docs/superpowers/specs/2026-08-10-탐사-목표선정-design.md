# 탐사 목표 선정 개선 — 설계

2026-08-10 · 대상 `src/ugv_vision/ugv_vision/patrol_navigator.py`

## 문제

큰 월드에서 로봇이 복도에 서서 시간을 버린다. 실측 로그(메인PC, 큰 월드):

```
338218  탐사 목표 → (-14.0, -3.7)  25.6m   먼 구역으로 출발
338219  후보 발견 (-0.8,15.3) — 정지 요청    1초 만에 멈춤
338227  조준 완료했는데 대상 없음 — 유령
338237  후보 발견 (-1.4,16.1) — 정지 요청
338242  탐사 목표 → (-14.0, -3.7)  24.5m   24초 동안 1.1m 전진
338252  후보 발견 (-1.3,15.2) — 정지 요청
```

24초에 1.1m. 원인은 둘이다.

### 원인 1 — 조사 중단이 목적지를 지운다

`_resume_patrol()` 이 `_frontier_goal = None`, `_far_lock = False` 로 되돌린다.
유령 후보(런당 21~24건) 하나마다 로봇이 어디 가려던 건지를 잊는다.
25.6m 목표를 세 번 재발행하고도 7m밖에 못 갔다.

### 원인 2 — 반경 5m 필터가 점수식을 무력화한다

목표 후보를 항상 반경 안에서 먼저 고른다.

```python
near = [c for c in self._find_visual_frontiers(...) if 반경 이내]
```

점수식 `n*0.5 - d` 는 이미 큰 덩어리를 선호하도록 돼 있는데, 필터가
비교 대상 자체를 눈앞으로 제한한다. 그래서 목표가 1.4~4.3m 잔걸음이
되고, 방 하나를 자투리 단위로 갉아먹느라 다른 방으로 못 넘어간다.
이것이 사용자가 지적한 "어느 방에 들어갈지 못 정한다" 의 실체다.

## 선행 실패에서 얻은 제약

2026-08-10 오전, 반대 방향을 시도했다가 실패했다(`e6dc4f3` 로 되돌림).
'지금 있는 방을 다 볼 때까지 머문다' 로 국소성을 **강화**했더니 큰
월드에서 목표의 90% 이상이 '방 마저 훑기' 가 되어 건물을 못 돌았다
(6/7, 5/7 — 기존 평균 6.3/7보다 나쁨).

**교훈: 탐사 예산이 유한하면 국소성을 강화하는 방향은 전부 위험하다.**
이번 설계는 국소성을 **약화**한다.

## 설계

### A. 중단된 목표를 복원한다

`_resume_patrol()` 은 목표를 버리지 않는다.

- 중단 직전의 `_frontier_goal` / `_frontier_src` / `_far_lock` 을 보존하고
  순찰 재개 시 같은 목표로 goal 을 재발행한다.
- **조사에 쓴 시간은 주행 예산에서 뺀다.** 중단 시각과 재개 시각의 차이만큼
  `_wp_sent_t` 를 뒤로 민다. 안 그러면 조사 시간 때문에 목표가 시간초과된다.
- 예외: 재개 시점에 그 목표가 이미 관측 완료됐으면 새로 고른다.

### B. 반경 필터를 없애고 전역 점수로 고른다

```
현재:  반경 5m 안 후보 → 비면 그때야 _pick_far_goal 로 먼 곳
바꿈:  전 지도 후보를 한 점수로 비교
       score = n − λ·d          (n = 미관측 셀 수, d = 직선거리 m)
```

- n=40짜리 1.4m 앞 자투리와 n=400짜리 20m 밖 미탐사 구역을 **같은 저울에**
  올린다. λ=5 기준 33점 대 300점으로 후자가 이긴다.
- 근거리/원거리 이중 모드가 사라진다 → `_pick_far_goal`, `far_goal_min_dist`,
  `sweep_first_r` 관련 분기 제거. **코드가 줄어든다.**
- 고른 목표는 도착/시간초과까지 붙든다(`_far_lock` 을 모든 목표로 확장).
  6초 재선정 주기마다 흔들리는 것을 막는다.

### 범위에서 뺀 것 — '미방문 방 보너스'

논의 때 언급했으나 1단계에서 제외한다. 방 단위 보너스를 계산하려면
되돌린 `_room_mask`(약 40줄)와 방별 상태 관리를 다시 들여야 하는데,
그것이 바로 직전에 실패한 복잡도다. 전역 점수만으로 큰 미관측 구역을
고르게 되므로 방 진입은 부수적으로 따라온다는 가설을 먼저 검증한다.

**검증에서 특정 방을 계속 건너뛰는 것이 관측되면 그때 추가한다.**

## 검증

| 단계 | 내용 | 중단 기준 |
|---|---|---|
| 1 | 단위 시험 — 점수 함수가 큰 덩어리를 고르는지 | 실패 시 중단 |
| 2 | 미니맵(18×12m, ~15분), λ 2~3개 비교 | 미니맵 불합격 시 폐기 |
| 3 | 큰 월드 2회 동시(OMEN, 각 4200초) | — |

**채택 기준(사전 고정)**

- 조난자 발견이 기존 평균 **6.3/7 이상**
- **그리고** 원거리 이동 완료율(발행한 먼 목표 중 실제 도달 비율)이 오를 것

둘 중 하나라도 못 미치면 되돌린다.
